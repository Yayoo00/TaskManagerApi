TaskManagerApi

API RESTful desarrollada con ASP.NET Core Web API (.NET 8), Entity Framework Core, SQLite y ML.NET.

Tecnologías utilizadas
ASP.NET Core Web API (.NET 8)
Entity Framework Core
SQLite
ML.NET
Swagger/OpenAPI
GitHub (Git Flow con ramas y Pull Requests)

Filtros

Ejemplos:

GET /api/Tareas?estado=Pendiente
GET /api/Tareas?prioridad=Alta
GET /api/Tareas?fechaInicio=2026-01-01&fechaFin=2026-12-31

API utilizada:

https://jsonplaceholder.typicode.com/todos

ML.NET - Análisis de Sentimiento

Dataset utilizado

Archivo:

Dataset/sentimientos.csv

Contiene ejemplos de frases positivas y negativas para entrenar el modelo.
